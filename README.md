# Laboratorio 5.1 – Primera Pantalla Declarativa

Validador de credenciales en tiempo real con Jetpack Compose (Kotlin, API 36).

- El mensaje cambia a verde con 3 o más caracteres.
- Desafío extra: el botón "Ingresar" se habilita solo con 5 o más caracteres.

Abrir con Android Studio → Open → seleccionar esta carpeta → Sync → Run ▶.
